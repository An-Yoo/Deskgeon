한국어

Deskgeon(이하 "이 확장 프로그램")은 브라우저 툴바에서 동작하는 방치형 RPG 게임입니다. 이 확장 프로그램은 개인정보를 수집하거나 판매하지 않으며, 개발자가 운영하는 서버도 없습니다.

1. 저장하는 정보

이 확장 프로그램이 저장하는 정보는 게임 진행 데이터(세이브) 뿐입니다. 레벨, 골드, 장비, 동료, 설정 등 게임 안의 값으로 구성되며, 이름·이메일·위치·방문 기록 같은 개인정보는 포함되지 않습니다.

2. 저장 위치

  • 사용자의 브라우저 안 (chrome.storage.local): 기본 저장 위치입니다.
  • 사용자의 크롬 계정 동기화 저장소 (chrome.storage.sync): 크롬 동기화를 켠 경우, 같은 계정의 다른 기기에서 이어 하기 위해 사용됩니다. Google이 크롬 동기화 정책에 따라 관리합니다.
  • 사용자의 Google 드라이브 앱 전용 숨김 폴더 (appDataFolder): 사용자가 설정에서 "Google 연결"을 직접 누른 경우에만 사용합니다. 이 확장 프로그램은 자신이 만든 세이브 파일 하나만 읽고 쓸 수 있으며, 사용자의 다른 드라이브 파일에는 접근할 수 없습니다(권한 범위: drive.appdata).

3. Google 로그인(identity 권한)

identity 권한은 Google 드라이브 연결을 위한 로그인에만 사용합니다. 로그인으로 받은 접근 토큰은 사용자의 브라우저 안에만 저장되며, 드라이브 세이브 파일을 읽고 쓰는 데만 쓰입니다. 설정에서 언제든 연결을 해제할 수 있습니다.

4. 제3자 제공

이 확장 프로그램은 어떤 정보도 개발자나 제3자에게 전송·공유·판매하지 않습니다. 광고, 분석 도구, 추적 코드를 포함하지 않습니다.

5. 웹페이지 접근

이 확장 프로그램은 사용자가 방문하는 웹페이지의 내용이나 방문 기록에 접근하지 않습니다.

6. 데이터 삭제

  • 확장 프로그램을 삭제하면 브라우저 안의 세이브가 함께 삭제됩니다.
  • 크롬 동기화 데이터는 크롬 설정의 동기화 데이터 관리에서 삭제할 수 있습니다.
  • 드라이브 세이브는 Google 드라이브 설정 > 앱 관리에서 Deskgeon의 숨김 데이터를 삭제할 수 있습니다.

English

Deskgeon ("the extension") is an idle RPG game that runs in the browser toolbar. The extension does not collect or sell personal information, and the developer operates no servers.

1. What is stored

The extension stores only game progress data (the save): in-game values such as level, gold, gear, allies and settings. It contains no personal information such as name, email, location or browsing history.

2. Where it is stored

  • In your browser (chrome.storage.local): the default location.
  • Your Chrome sync storage (chrome.storage.sync): if Chrome Sync is on, so you can continue on another device signed in to the same account. Managed by Google under Chrome Sync policies.
  • The hidden app-data folder of your Google Drive (appDataFolder): only if you press "Connect Google" in the settings. The extension can read and write only the single save file it created and cannot access any other file in your Drive (scope: drive.appdata).

3. Google sign-in (identity permission)

The identity permission is used only to sign in for the Google Drive connection. The access token is kept only in your browser and is used only to read and write the Drive save file. You can disconnect at any time in the settings.

4. Third parties

The extension does not send, share or sell any information to the developer or any third party. It contains no ads, analytics or tracking code.

5. Web page access

The extension does not access the content of web pages you visit or your browsing history.

6. Deleting data

  • Uninstalling the extension deletes the save stored in the browser.
  • Chrome sync data can be removed from Chrome's sync data settings.
  • The Drive save can be removed in Google Drive Settings > Manage apps > Deskgeon > Delete hidden app data.
