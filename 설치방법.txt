Deskgeon - 방치형 던전 RPG 설치 방법 (크롬 / 엣지 / 웨일 / 브레이브)

1. 이 압축파일을 원하는 곳에 풀어요. (예: 문서\Deskgeon)
   * 풀어둔 폴더를 지우거나 옮기면 게임도 사라지니까 계속 둘 곳에 풀어주세요.
2. 주소창에 입력:  chrome://extensions   (엣지는 edge://extensions)
3. 오른쪽 위 "개발자 모드" 켜기
4. "압축해제된 확장 프로그램 로드" 클릭 → 방금 푼 폴더(manifest.json이 들어있는 폴더) 선택
5. 툴바의 퍼즐 아이콘 → Deskgeon 옆 핀 눌러 고정 → 아이콘 클릭하면 시작

업데이트 받을 때: 새 압축파일을 같은 폴더에 덮어쓰고, 확장 프로그램 페이지에서 Deskgeon의 새로고침 버튼을 누르면 돼요. 세이브는 그대로 남아요.

* 브라우저를 켤 때 "개발자 모드 확장 프로그램 사용 중지" 알림이 뜰 수 있는데, 무시하거나 닫으면 돼요.
* 개인정보는 쓰지 않아요. 세이브는 내 브라우저와 (동기화를 켰다면) 내 크롬 계정에만 저장돼요.
* 도트 그래픽: Dungeon Crawl Stone Soup CC0 타일 (자세한 건 CREDITS.md)

[세이브 / 계정 동기화]
* 크롬에 구글 계정으로 로그인하고 동기화를 켜두면(설정 > 동기화 > 확장 프로그램 포함) 세이브가 계정에 저장돼서,
  다른 PC의 같은 계정 크롬에 이 확장을 설치하면 이어서 할 수 있어요.
* 동기화를 안 쓰면: 게임 오른쪽 위 톱니바퀴(설정) > "세이브 코드 복사" → 다른 PC에서 "세이브 코드 불러오기"로 옮길 수 있어요.
* 30분마다 자동 백업이 6개까지 남아요. 설정(톱니바퀴) > 백업에서 복구할 수 있어요.
* 폴더 위치를 옮기거나 다시 설치해도 확장 ID가 고정돼 있어서 동기화된 세이브를 그대로 찾아요.
